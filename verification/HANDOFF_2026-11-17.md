# 花月汀 v0.2 · 2026-11-17 交付

接续 Hermes 中断前最后的承诺：回测钓鱼、买饵与存档流程，并更新包含自由划船和 Blender 小狼的项目包。

双击项目根目录「启动花月汀.cmd」，保持终端窗口打开。浏览器地址为 http://127.0.0.1:4173/ 。需要本机 Node.js 18 或更新版本，不需要 npm install 或 CDN。游戏没有真实货币交易。

小船可用 WASD、方向键或手机方向按钮移动；停桨或抛竿后停船，地图与册子打开时暂停，回到码头可救援。钓鱼完成后选择放归或交换，都会写入图鉴；花月币可购买鱼饵与鱼竿，进度和注记保存在浏览器本地。

本次保留已有玩法，完成 v0.2 版本一致性、可观察的只读游戏状态、旧说明修正和预览 PNG 本机路径元数据清理。PNG 的图像数据没有修改。

实际浏览器验收通过：四季、时段、六处地图、乘船、钓鱼全流程、放归、交换、图鉴注记及重载、购竿换竿、购船和买饵扣款、键盘与手机划船、停泊、菜单暂停、回码头。结果见 results.json、sailing-results.json 和 economy-results.json，核心流程无控制台错误。数据检查覆盖 36 条鱼、各水域季节时段的可用鱼池、六星保底和航行边界；模型检查确认 GLB 使用本地数据，无外部资源 URI。

已直接查看实际游戏的桌面划船、捕获结算和手机截图。游戏实际加载 Blender GLB。可编辑源文件在 assets/wolf-girl.blend。

当前是可玩概念原型。六处水域仍复用场景结构，角色仍为粗模；独立关卡精修、自由步行、生产级骨骼和美术不是今天交付范围。原构思、36 鱼目录和技术路线保留于设计书与 CSV。

补充修复：1280×720 等矮窗口中的装饰便笺曾挡住划船按钮，已在窗口高度不超过 850px 时收起便笺。航行回归新增该尺寸真实点击停桨／出发，见 12-sailing-laptop.png。
